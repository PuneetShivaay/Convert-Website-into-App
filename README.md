## 🚀 About the Project

**Convert Website into App** is a Flutter-based application template that allows you to display your website inside a mobile application using WebView.

Instead of building a mobile application from scratch, you can update the website URL and application title to customize the app for your own website.

This project is a simple starting point for developers who want to explore:

- Flutter development
- WebView integration
- Cross-platform mobile development
- Website-to-app conversion

## ⚙️ Getting Started

### Prerequisites

Make sure Flutter is installed and configured on your system.

Check your Flutter installation:

```bash
flutter doctor
```

You can install Flutter from the official Flutter documentation.

---

## 📥 Installation

### 1. Clone the repository

```bash
git clone https://github.com/PuneetShivaay/Convert-Website-into-App.git
```

### 2. Navigate to the project directory

```bash
cd Convert-Website-into-App
```

### 3. Install dependencies

```bash
flutter pub get
```

---

## 🔧 Configure Your Website

Open the following file:

```text
lib/src/app.dart
```

Update the existing website URL with your own website URL.

For example:

```text
https://your-website.com
```

You can also update the application title according to your project requirements.

After updating the configuration, you are ready to run the application.

---

## ▶️ Run the Application

Connect a physical device or start an emulator.

Then run:

```bash
flutter run
```

The application can be run on supported Flutter platforms depending on your development environment.

---

## 💡 How It Works

```text
Your Website
     │
     ▼
Flutter Application
     │
     ▼
WebView
     │
     ▼
Mobile App Experience
```

The Flutter application loads the configured website inside a WebView, allowing users to access the website through a mobile application interface.
